# Desafio Criativo — Análise de Feedbacks de Clientes sobre Cartão de Crédito

## Prompt Final

Atue como analista de dados e experiência do cliente em um banco.

Sua tarefa é analisar feedbacks de clientes sobre cartão de crédito para identificar problemas relacionados a limites, tarifas, faturas, cobranças e atendimento, propondo soluções práticas para os problemas identificados.

### Contexto

A análise será usada por gerentes do banco para compreender os principais problemas relatados pelos clientes, priorizar aqueles que precisam ser corrigidos e definir soluções para melhorar os serviços relacionados ao cartão de crédito.

### Dados disponíveis

A base contém:

* Data
* Canal de atendimento
* Comentário do cliente
* Produto
* Nota de satisfação de 1 a 5

### Instruções de análise

1. Classifique os feedbacks por tema, sentimento, urgência, produto e canal.
2. Identifique os principais problemas, padrões e oportunidades de melhoria.
3. Aponte evidências encontradas nos comentários fornecidos.
4. Proponha soluções práticas para os problemas identificados.
5. Indique quais problemas devem receber maior atenção, com base nas informações disponíveis.

### Formato da resposta

Apresente um resumo dos principais problemas encontrados, seguido de uma tabela contendo:

* Problema
* Tema
* Sentimento
* Urgência
* Evidência
* Solução sugerida

### Restrições

* Use apenas os dados fornecidos.
* Não invente números, causas ou conclusões.
* Não exponha dados pessoais ou sensíveis.
* Informe limitações quando os dados não forem suficientes.
* Use linguagem simples, profissional e objetiva.
